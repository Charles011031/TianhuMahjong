> 并支持**装成手机 App**（PWA）。

## ✨ 功能一览

### 🀄 桌台计时
- 6 张桌台，独立计时、统一价格（每小时费率可改）
- **暂停 / 继续**，暂停期间不计费
- **换桌**（把一场挪到另一张桌）
- **自定义时间 / 补录**（客人走了才想起来没按结束）
- **改结束时间**（算错了直接改）
- **待结算**：先停表不收钱，桌子空出来给下一桌，回头再收

### 💰 结算收费
- 四种收款方式：**现金 / 刷卡（自动加手续费）/ 人民币（自动按汇率折算）/ 会员余额**
- **会员余额只能抵台费**，零食必须另付（程序层强制）
- **台费+零食合成一笔收**（默认开），免得同一个客人刷两次卡
- **分次结算**：一次没收齐可以「记在桌上」，之后点【补收】继续收
- 桌台卡片上显示「上次未付 $X」红色角标

### 👥 按人分账
- 台费按人数平分，支持**一人代付多人台费**
- 零食按**份数**分给具体的人（3 瓶可乐各归各人，不是整样平分）
- 可选「台费+零食合成一笔」或「分开成笔」
- 每行显示「已分 2/2 ✓」自动校验有没有分完
- 一键填入收款明细

### 🎫 会员
- 充值档位（可自定义：充 500 送 100 之类）
- 余额抵扣台费、充值赠送金额自动算
- **流水可改可删**（删的是软删除，数据留痕可恢复）
- 改/删流水后**余额自动顺着整条流水重算**
- 会员资料可改（姓名 / 电话）
- 充值提成：可指定归谁 / 工资页可「补分配」/ 还在上班的班次也算

### 🕐 员工
- 上班打卡 / 下班打卡 / 自动算工时
- **新员工上班时自动给上一位打下班**（免得忘打卡）
- 班次（白班 / 晚班）自动或手动
- 忙日加成（当天营业额超阈值，每小时 +$1）
- 工资汇总：工时 / 提成 / 忙日加成 / 总计
- **名片拖动排序**（支持左右上下）
- 头像、改名字

### 📊 统计
- 按营业日 / 本月合计
- 台费 / 零食饮料 / 鸭嘴兽 / 总额 / 人民币 / 会员充值
- 当日明细，可按类型筛选、搜索
- **结算记录按结束时间倒序**（刚结完的排最上面）

### 🍜 零食饮料 / 🦆 鸭嘴兽
- 菜单可拖拽排序、分类、库存管理
- 可以单独结算，也可以**挂到桌上**之后一起结
- 电子烟按代/按条，支持加价和刷卡手续费

### 📅 预约
- 日期 / 时间 / 姓名 / 电话 / 桌号 / 备注
- **多设备同步**

### 🔄 多设备实时同步
- 手机 / 平板 / 电脑同时记账，改动几秒内同步
- 同步范围：结算记录、会员、打卡、库存、员工、设置、
  **桌台状态（含结束时间 / 挂在桌上的零食 / 未付款）**、预约、待结算
- **断网也能记**，有网了自动补传
- 数据在 **Firebase 云端**，不在浏览器里 —— 换设备、清缓存都不丢

### 📤 导出到 Google 表格
- 独立的定时任务，每 5 分钟把数据同步到 Google 表格
- 可以在表格里做图表、透视表

## 📁 目录说明

```
├── index.html      ← 网页本体（就是整个系统，单文件）
├── manifest.json   ← PWA 配置（App 名字、图标、颜色）
├── sw.js           ← Service Worker（离线缓存，网络优先）
├── assets/         ← 图标
│   ├── icon-180.png           苹果手机用的
│   ├── icon-192.png           安卓用的
│   ├── icon-512.png           高清
│   └── icon-maskable-512.png  安卓自适应图标
└── README.md
```

> **关于位置**：`index.html` / `manifest.json` / `sw.js` **必须放在根目录** ——
> GitHub Pages 的入口、以及 Service Worker 的作用域都要求这样，**请勿移动**。

## 🏗 技术架构

```
前端     单文件 HTML（约 600 KB），无框架、无构建步骤、无依赖
数据     Firebase Realtime Database（多设备实时同步）
托管     GitHub Pages（静态）  ← v3.0 起
离线     Service Worker（网络优先：保证永远拿到最新版）
导出     独立的 Apps Script 定时任务 → Google 表格
```

## 🚀 更新流程

```
改代码 → 生成 → 一条命令同步两个地址（由维护脚本自动完成）
你不需要做任何事，打开网页就是最新版
```

## ⚠️ 数据安全

- 数据在 **Firebase 云端**，不在浏览器里 —— 换设备、清缓存都不会丢
- 网页文件本身**不含任何密码或密钥**
- 建议定期用系统里的「备份」功能导出完整 JSON
- **已知待改进**：Firebase 规则目前允许匿名读写，
  安全性依赖「网址不外传」。若要收紧，可加 Firebase Auth 或访问口令。
