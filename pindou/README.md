# 拼豆店 · 工位看板

10 个工位的计时/收费/烫位看板，给悉尼拼豆店用。

**线上**：https://charles011031.github.io/PinDouShop/

## 现在能做什么

- 10 个工位：选板型（智能板 / 普通板）开台，暂停 / 继续 / 结束。
- 两种计费：按小时（15 分钟进位、最低 30 分钟）或 2 小时套餐（超时按 15 分钟补）。
- 结算：现金 / 刷卡（手续费可设）、会员折扣；收款后作品自动进烫位队列。
- 2 个烫位：排队 → 熨烫中 → 可取件 → 已取走。
- 今日营收/单数/使用中/烫位等待/可取件统计；今日收款列表。
- 设置：两个板型时价、套餐价、套餐分钟、超时价、刷卡手续费、会员折扣；改完即时生效，只影响新开台。
- 多设备同步：Firebase Realtime Database 新表（与天胡门店数据隔离），3 秒轮询；断网自动用本机缓存，联网后补写。

## 数据

- 浏览器本地：`localStorage` 键 `pindou_board_v1`。
- 云端：同一个 Firebase 项目下的新路径 `shops/<独立 key>/state`，不碰天胡的 `shops/<天胡 key>`。
- 当前是匿名读写（和天胡同款），**网址不要发群/朋友圈**；正式营业前建议加 Firebase Auth / 门店 PIN。

## 价格

页面里的默认价只是占位示意：智能板 A$15/h、普通板 A$10/h；2 小时套餐 A$28 / A$18。
老板定价后，在页面右上角「⚙ 设置」里改即可，不用改代码。
